# DashForge

A blockchain-based data visualization and analytics platform built on Stacks. DashForge enables users to create, manage and share dashboards while maintaining data integrity and ownership through blockchain technology.

## Features
- Create and manage visualization dashboards
- Store dashboard configurations on-chain
- Share dashboard access with other users
- Track dashboard version history 
- Monetize dashboard templates through marketplace
- Purchase and clone templates from other creators
- Template ownership verification and payments

## Contract Functions
- Create new dashboards
- Update dashboard configurations
- Manage dashboard access rights
- Share/transfer dashboard ownership
- Track dashboard version history
- Convert dashboards to purchasable templates
- Purchase templates using STX tokens
- Clone templates to create new dashboards

## Template Marketplace
The template marketplace allows dashboard creators to monetize their work by:
- Converting existing dashboards into purchasable templates
- Setting custom prices in STX tokens
- Earning STX when others purchase their templates
- Building a portfolio of template offerings

Templates can be purchased by other users who receive their own copy of the dashboard to customize and use.
